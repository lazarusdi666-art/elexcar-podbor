Управление приложением

Клиенты этот экран не видят: в меню бота его нет.

Подключить к боту

  1. @BotFather → /mybots → @elexcar_podbor_bot.
  2. Bot Settings → Menu Button → Configure menu button → ссылка на приложение → название «Подобрать авто».
  3. Чтобы работала кнопка «Поделиться машиной»: Bot Settings → Configure Mini App → Enable → та же ссылка.

Новые машины из канала

После запуска бот — администратор канала @elexcar. Новый пост с ценой под ключ сам появляется в каталоге: название, год, пробег, мощность, цена, город и фото. Вы только отмечаете проданные ниже.

Наличие

Отметьте проданные — они уйдут в конец списка с пометкой «Продано». В тесте отметки видны только в этом браузере.
